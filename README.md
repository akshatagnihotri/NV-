# 3D Interactive Typography Portfolio

A stunning, interactive 3D particle typography portfolio built with Svelte, Three.js, and Vite. As you scroll down the page, a 3D sphere of particles beautifully breaks apart and morphs into different Chinese characters.

## 🚀 Live Demo

**Check out the live project here:**  
👉 [https://akshatagnihotri.github.io/NV-/](https://akshatagnihotri.github.io/NV-/)

## ✨ Features

- **Interactive 3D Particles:** Thousands of particles reacting to scroll and mouse movements.
- **Dynamic Typography:** Smooth morphing transitions between 3D text.
- **Native Canvas Rendering:** Utilizes system fonts for rendering Chinese characters dynamically, eliminating the need for bulky external font files.
- **Built with:** Svelte, Three.js (`@threlte/core`), and Vite.

## 🛠️ Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akshatagnihotri/NV-.git
   cd NV-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
